# CCN London Colour Variations

This package contains three copies of the same static HTML website. Components, layout, copy, assets, spacing, typography, and interaction structure are unchanged. Only accent-related colour values were replaced.

| Folder | Primary Accent | Hover / Deep Accent | Light Accent Tint |
|---|---:|---:|---:|
| `accent-0892D0` | `#0892D0` | `#056996` | `#E6F4FB` |
| `accent-0033AA` | `#0033AA` | `#002280` | `#E5EAF5` |
| `accent-0057AD` | `#0057AD` | `#003E7A` | `#E6EEF7` |

## Implementation notes

The original site used `#00AEEF` as the primary cyan accent, `#0077A8` as the deeper hover/accent value, `#E8F6FD` and several pale blue backgrounds as light accent tints, plus matching RGBA accent shadows and overlays. Each variation maps those accent-related colours to the requested blue while retaining the same selectors and component structure.
